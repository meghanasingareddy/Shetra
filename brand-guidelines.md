# Brand Guidelines — Shetra

## Colors

| Token         | Hex       | Usage                          |
|---------------|-----------|--------------------------------|
| Black         | `#0B0C10` | Page background                |
| Dark          | `#14151B` | Section backgrounds            |
| Surface       | `#1C1E26` | Cards, inputs, modals          |
| Light         | `#F4F4F6` | Primary text, headings         |
| Neon          | `#FF2E63` | SOS, CTAs, active states       |
| Muted Rose    | `#C7364F` | Secondary accent, hover states |
| Text Muted    | `#8B8D97` | Captions, hints, placeholders  |

## Typography

| Role      | Font Family | Weight | Size    |
|-----------|-------------|--------|---------|
| Heading   | Outfit      | 700    | 1.75rem |
| Subhead   | Outfit      | 600    | 1.25rem |
| Body      | DM Sans     | 400    | 1rem    |
| Caption   | DM Sans     | 400    | 0.875rem|

## Rules

- Dark base dominates all screens.
- Neon pink (#FF2E63) used ONLY for SOS, primary CTAs, active states, and critical alerts.
- No pink backgrounds or gradients.
- Maintain minimum 4.5:1 contrast ratio for text.
- Prefer subtle glass layers over hard borders.
