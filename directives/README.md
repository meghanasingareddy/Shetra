# Directives

This folder contains Markdown SOP documents (Layer 1 of the 3-layer architecture).

Each directive defines:
- **Objective** – What needs to happen
- **Inputs** – What data or context is required
- **Tools / Scripts** – Which execution scripts to call
- **Outputs** – Expected deliverables
- **Edge Cases** – Known pitfalls and how to handle them

Directives are living documents — update them whenever you discover new constraints, better approaches, or common errors.
